# Captain Rakesh Mohan Shyam Degree College

Official website for **Captain Rakesh Mohan Shyam Degree College**, Bharnakalan, Mathura.

- **College Code:** 0538
- **Affiliation:** Dr. B. R. Ambedkar University, Agra
- **Location:** Bharnakalan, Mathura, Uttar Pradesh

## Features

- Fullscreen background carousel showcasing campus grounds and buildings
- Clean, minimal institutional branding and details
- Interactive thumbnail switcher and keyboard navigation (`←` / `→` arrow keys)
- Responsive design optimized for mobile, tablet, and desktop
- Static asset hosting support (Cloudflare Pages / Workers via `wrangler.jsonc`)

## Local Development

Simply open `index.html` in any web browser, or serve locally with Python:

```bash
python3 -m http.server 8080
```
