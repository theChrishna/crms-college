Accessibility Statement

Commitment to Digital Inclusivity, WCAG 2.1 AA Standards & Universal Access

Universal Access

Digital Accessibility Commitment

Guidelines Conformance: W3C WCAG 2.1 Level AA · Captain Rakesh Mohan Shyam Degree College

Captain Rakesh Mohan Shyam Degree College is committed to ensuring that our digital portal is accessible to all individuals, including prospective rural students, learners with disabilities, and users navigating via assistive technology. We firmly believe educational information should be barrier-free and universally available.

1. Compliance Standards

This website is engineered to conform with Level AA of the World Wide Web Consortium (W3C) Web Content Accessibility Guidelines (WCAG) 2.1. These standards outline technical criteria across four fundamental accessibility principles: Perceivable, Operable, Understandable, and Robust.

2. Core Accessibility Features Implemented

  • Full Keyboard Navigation: All interactive elements, including menu triggers, dropdowns, search topper drawer, and forms, can be fully operated using standard keyboard controls (Tab, Shift+Tab, Enter, Space, and Escape) with clearly defined high-contrast focus rings.
  • Skip to Content Link: A direct skip link is embedded as the first navigable element on every page (Skip to content ↓) to allow screen reader and keyboard users to bypass repeating header links.
  • High-Contrast Color System: Text and UI elements maintain a color contrast ratio exceeding 4.5:1 against their backgrounds, strictly following the MIT Admissions color aesthetic (deep black `#111111` on `#ffffff` / `#f7f7f5`).
  • Semantic Document Architecture: Pages utilize standard HTML5 landmark elements (<header>, <nav>, <main>, <footer>), structured heading hierarchies (h1 through h4), and accessible tables with programmatic <th> scope attributes.
  • Scalable Typography & Zoom: The layout is built with fluid responsive sizing that supports browser zoom up to 200% without clipping content or forcing horizontal viewport breaks.
  • Alternative Text for Images: All campus photographs, college crests, and graphic assets include descriptive alt text for screen readers.
  • Accessible Forms: All inputs feature programmatic <label> associations, explicit error notifications, and touch targets sized at 44×44 pixels or larger.

3. Assistive Technology Compatibility

The website is tested for compatibility across standard assistive platforms, including NVDA, JAWS, Apple VoiceOver, Android TalkBack, and modern standards-compliant web browsers (Chrome, Edge, Firefox, Safari).
